Integration: How InsightAgent Fits

Wiring into the orchestrator, router, and Celery workers

Flow 1: Auto-Scan on Stave Creation
User creates stave
→
POST /staves/
→
Connection tested OK
→
Dispatch Celery task
run_auto_scan(stave_id)
→
InsightAgent runs
stages 1-3 + 5
Non-blocking — user gets immediate "stave created" response. Scan runs in background via checks.default queue. On completion: data_profile created, baseline_snapshot stored, initial insight_report generated, suggested checks auto-created.
Flow 2: On-Demand via Chat
"What's going on
with my sales data?"
→
RouterAgent
intent: insight
→
InsightAgent
loads profile + history
→
Runs stages 3-5
(fresh snapshot + analysis)
→
Natural language
response in chat
Synchronous in the chat flow. RouterAgent detects "insight" intent and routes to InsightAgent. InsightAgent loads the existing data_profile (no need to re-discover schema) and focuses on fresh analysis. Can also be chained: InsightAgent → ConfigAgent if user wants to act on suggestions.
Flow 3: Scheduled Daily Intelligence
Celery Beat
cron: 0 6 * * *
→
For each active stave:
run_daily_intelligence(stave_id)
→
InsightAgent runs
full pipeline (1-5)
→
Compare vs previous
snapshots & reports
→
Dashboard updated
Alerts if critical
Runs on checks.default queue alongside regular quality checks. Produces a new baseline_snapshot + insight_report. Compares against last 7/30/90 day windows. If anomalies found with severity ≥ high, can trigger notification (future: email/webhook).

New API Endpoints

Dashboard and insight delivery

GET  /insights/{stave_id}/profile       # Current data profile (domain, schema map)
GET  /insights/{stave_id}/latest        # Most recent insight report
GET  /insights/{stave_id}/history       # Historical reports (paginated)
GET  /insights/{stave_id}/dashboard     # Aggregated dashboard view (scores, trends, alerts)
POST /insights/{stave_id}/analyze      # Trigger on-demand analysis
GET  /insights/overview                # Cross-stave summary (all data sources at a glance)
GET  /insights/{stave_id}/suggestions   # Pending AI suggestions (accept/dismiss)
POST /insights/{stave_id}/suggestions/{id}/accept   # Accept a suggestion
POST /insights/{stave_id}/suggestions/{id}/dismiss  # Dismiss a suggestion
