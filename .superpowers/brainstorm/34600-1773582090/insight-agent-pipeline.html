InsightAgent: Intelligence Pipeline

How data flows from raw tables to business insights

1
Discovery
AUTO-SCAN (runs on stave creation)
What it does:
Lists all tables, counts rows, reads column types, samples 100 rows per table, detects primary/foreign keys
Output:
DataProfile — schema map, row counts, column stats, detected relationships
2
Classification
AUTO-SCAN (runs on stave creation)
What it does:
LLM analyzes the schema + samples to classify the domain. "This looks like an e-commerce database with orders, products, and customers."
Output:
DomainClassification — domain type, entity roles (fact tables, dimensions), business context
3
Baseline Snapshot
AUTO-SCAN + DAILY RUN
What it does:
Captures quantitative baselines: row counts, null rates, value distributions, freshness timestamps. First run = initial baseline. Daily runs = new snapshots for comparison.
Output:
BaselineSnapshot — timestamped metrics per table/column, stored for trend analysis
4
Business Analysis
DAILY RUN + ON-DEMAND
What it does:
LLM receives: domain classification + current snapshot + historical snapshots + existing check results. Produces business-level analysis.
Examples:
"Order volume down 18% week-over-week"
"New customer signups plateauing"
"High null rate in email column suggests data collection issue"
5
Suggest + Act
ALL TIERS
Auto-creates:
Quality checks based on discovered patterns (tagged source: ai-generated)
Generates:
InsightReport — scored dimensions, trend comparisons, actionable suggestions, structured for dashboard + chat

LLM Prompt Strategy

How the AI gets smart about your specific data

Context Window
Each analysis call sends:

1. Domain classification
2. Schema summary (not raw DDL)
3. Key metrics from current snapshot
4. Delta from last N snapshots
5. Existing check results (pass/fail)

Compressed, not raw data — keeps token costs manageable
Structured Output
LLM returns Pydantic models:

InsightReport
  ├ health_score: 0-100
  ├ dimensions: [{name, score, trend}]
  ├ anomalies: [{description, severity}]
  ├ suggestions: [{action, reasoning}]
  ├ summary: str (natural language)
  └ checks_to_create: [ClefCreate]

Structured = dashboardable + chatbot-friendly
