# Podium is a deployable application, not a library, so its dependencies are
# pinned exactly. With >= ranges a fresh CI run resolves whatever is newest on
# the day, against code that has not changed. That is how pydantic-ai 1.x to
# 2.x landed mid-branch and removed OpenAIModel, and how FastAPI 0.141 changed
# include_router to store lazy wrappers.
#
# The pulse connector packages stay on ranges. They are libraries, and pinning
# a library's dependencies pushes conflicts onto whoever installs it.
#
# To bump: change the pin, then run `uv run pytest datametronome/podium/tests/`
# and `uv run ty check`. Use uv run, not the podium venv, because that is what
# CI resolves.
